Setup guide
  1. Create a project at Supabase Dashboard.
  2. Open Project Settings → API (or Data API / API Keys, depending on the dashboard version). Copy the Project URL and the publishable key, or legacy anon key. Do not use the service-role/secret key.
  3. Paste both values above. Choose a room code and click Connect / Join room.
  4. Your friend opens the same published website, enters the same Supabase values and room code, then clicks Connect. First person is En; second is Um.
  5. To publish: upload index.html, en.png and um.png to your GitHub repository. Open Settings → Pages, select Deploy from a branch, choose main and /(root), then Save.

Prototype note: this is a learning build using client-side realtime messages, not a cheat-resistant competitive server. A production version should use server-authoritative game rules.
